Several live rules are intentionally conservative: a class is only judged when every annotation is canonical `jakarta|javax.persistence` (or the registered Lombok/Spring names) and no wildcard import hides an owner, so a real project file with extra annotations may stay quiet. The defect files are written to satisfy those gates.
