3. Runtime cache-only observation search across category/title/retained details, visible/retained counts and clear control. Query stays in the same scope and is withdrawn on project/URL/auth changes. Tests exercise no-match, reset and project switch without HTTP.
4. Runtime typed HTTP method filtering (All observations or one standard method), based solely on structured method metadata, not predicate text. Scope-retention/project-switch tests added.
5. Runtime request-file creation with exact preview, root-owned plain .http filename, collision/refusal and post-prompt source/scope revalidation. Tests cover creation/open, occupied file preservation, traversal refusal and cancel. Optional project.write permission.
6. Runtime explicit local GET/HEAD request sending from structured reported mapping; user supplies concrete local URL and confirms exact method/URL. No actuator credentials/custom headers/body reuse. Plain selected-row HTTP Response detail includes status/bytecount and up to64KiB body; headers omitted. Tests cover local success, external host/refused unresolved path/control injection, cancel and response row isolation.
7. Runtime selected mapping HTTP request template export. Snapshot stores serde-defaulted exact reported method/path pairs (legacy snapshots remain readable), bounded to32 combinations, rejects unknown/empty methods, protocol-relative paths and whitespace/control characters. Exports selected current record only using optional clipboard capability, never parses predicate text or sends network requests. Templates explicitly require application origin and required arguments to be reviewed. Tests cover both method export and stale-scope refusal, missing metadata, malformed paths/methods and legacy unsafe records.

## Precise remaining scope (not a full parity claim)
Initializr complete binary-wrapper/executable/empty-directory generation now has a reviewed optional Python adapter, outside-project destination, bounded staging and exclusive commit/open workflow. Remaining plugin work includes broader effective Maven/Gradle build-model acceptance, non-start.spring.io server grants, and preservation of arbitrary ZIP timestamps/nonstandard permission modes beyond normalized644/755. These are not all host blockers. Native New Project integration, JDK/SDK configuration and automatic IDE build import need appropriate host interfaces.
Runtime plugin work still includes request selection-specific dependency/injected-bean popup parity, library/source distinctions with complete external semantics, saved-request/history and externally managed credential selection; local direct sender now supports all reported standard methods with explicitly entered headers/body. Management transport is HTTP/loopback only; full remote/JMX connection adapter is not implemented. Debugger live object evaluation, run configuration restart/override and native code hot-swap require host APIs. Snapshot observations are not debugger state. No proprietary original code/assets were used.

## Exact-condition and related-bean follow-up
- `request_conditions.rs` consumes only structured Actuator headers/params/consumes/produces clauses, preserving positive/negative/unknown distinctions. Known literal values supply editable request examples; query values are encoded; unsupported clauses remain review text, not invented facts. A concrete single media type can supply editable Content-Type/Accept; no Java body schema is guessed. Legacy caches deserialize empty examples as unreported. - `panes.rs` now offers Related Beans for selected bean observations. Outgoing relations require a verified dependency array; incoming relations require verified arrays on the dependent. Both require unique same-context bean-name ownership, then the existing exact current-project qualified-source resolver. Ambiguous, external, parent-context and incomplete-index cases remain unavailable. Relations are bounded and cache-only.
- Regression coverage: structured mapping-condition end-to-end template output, positive/negated/unknown conditions and encoding, context-isolated relation chooser with actual source opening, and retiring a preceding successful CLI result when a new generation starts then fails.
