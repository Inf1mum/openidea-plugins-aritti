# PropertiesGraph semantic helper

New files only: `plugins/properties/adapters/PropertiesGraph.java`, `PropertiesGraphTest.py`. No existing plugin/Rust/shared files edited for this task.

The standalone Java17-compatible helper uses real JavacTask parse/analyze and Trees/Elements/Types semantic bindings, never application/bootstrap execution, generation or annotation processing. Explicit bounded source snapshots overlay a complete physical walk of declared conventional Java roots, including ignored/hidden files. Empty classpath/sourcepath, `-proc:none`, `--release17`, `-implicit:none`. CLI source mode tested: `java --source 17 PropertiesGraph.java REQUEST OUTPUT`.

Protocol accepted by parent: PROPERTIES_GRAPH_V1 input ROOT/SOURCE_ROOT/SOURCE optional BUNDLE, UTF8 hex tab fields; output complete/incomplete with source64hexSHA256, whole-literal UTF16 EDGE ranges and decoded bundle/key, all sibling .properties BUNDLE inventory paths, UNKNOWN reasons and END counts. Output is bounded256KiB and atomically moved from a sibling tempfile. Classpath input is intentionally rejected v1.

Semantic binding supports canonical single-string java.util.ResourceBundle.getBundle origins through explicit final fields/locals/aliases, constant bundle names, getString/getObject/getStringArray/containsKey, canonical org.jetbrains.annotations.PropertyKey parameter/field/assignment/return/type-use contracts and overload/constructor/varargs binding. Literal source spans include quotes and escapes; decoded key comes from compiler LiteralTree. Constant-variable key arguments are withheld rather than editing shared constant definitions. Inherited PropertyKey contracts without explicit override annotations, dynamic names/receivers/keys, method references, custom getBundle overloads, class ResourceBundles, unresolved compiler diagnostics, Kotlin sources, symlinks and source drift force incomplete.

Inventory limits400 Java files128KiB/source4MiBtotal512dirs8192entries4096entries/dir200resource siblingsdepth24time8s1024edges. Request/source reads use bounded NOFOLLOW InputStreams, strict UTF8. Directory membership, attrs and physical Java SHA256 are rechecked after compilation. Parent must impose an external deadline because javac analysis itself may not interrupt at the internal tick. Renaming remains a native reviewed transaction with fresh before/after helper runs and exact snapshot comparison, not a provider-side compiler process.
