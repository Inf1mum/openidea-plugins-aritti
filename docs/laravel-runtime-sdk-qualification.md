# Runtime integrations: exact API 1.4 qualification

**Current user scope:** Qodana is explicitly excluded under plugin-only delivery (confirmed2026-11-11). The Qodana adapter analysis below is historical boundary evidence, not remaining required work. Exact agent-finished event absence is additionally qualified in [baseline research](laravel-baseline-qualification-20261111.md); helper generation itself remains implemented.
This qualification uses the plugin's pinned `openidea-plugin` SDK/host source at `37c2a60` (CLI 0.1.40), not the installed older CLI. Source availability is distinct from account provisioning, a live service acceptance run, and production feature completeness.

## Secret transport and Sentry authorization

The [SDK HTTP request](https://github.com/l0ng-ai/openidea/blob/37c2a60/sdk/rust/openidea-plugin/src/types.rs) documents `{{secret:name}}` substitution on header values. The [host fetch adapter](https://github.com/l0ng-ai/openidea/blob/37c2a60/crates/ide-plugin/src/wit_host.rs) checks header placeholders and forwards request body bytes unchanged. The [host SDK](https://github.com/l0ng-ai/openidea/blob/37c2a60/sdk/rust/openidea-plugin/src/host.rs) exposes secret set/delete/is-set, not secret read or a secret-bearing form body template. It also exposes an OAuth loopback callback; lack of loopback is **not** the restriction.

[Sentry's OAuth documentation](https://docs.sentry.io/api/auth/) specifies registered client credentials and token exchange/refresh form fields. The plugin implements an explicit registered-client device grant flow, bounded native-session device code, browser handoff, explicit rate-limited polling, keychain access/refresh token storage, expiry rejection, cancellation and disconnect cleanup. It ships no registered client and has no live registered-client acceptance receipt. Persistent refresh cannot safely take a stored refresh token into Sentry's form body using this ABI. No plaintext storage fallback or hidden backend is used. OAuth is therefore partial, not complete; a host secret-form request primitive or separately provisioned secure exchange service remains necessary for persisted refresh.

## Terminal completion

The pinned [provider exports](https://github.com/l0ng-ai/openidea/blob/37c2a60/sdk/rust/openidea-plugin/src/providers.rs), [language feature callbacks](https://github.com/l0ng-ai/openidea/blob/37c2a60/sdk/rust/openidea-plugin/src/language_features.rs), [execution interfaces](https://github.com/l0ng-ai/openidea/blob/37c2a60/sdk/rust/openidea-plugin/src/execution.rs), and [manifest](https://github.com/l0ng-ai/openidea/blob/37c2a60/crates/ide-extension/src/manifest.rs) contain no terminal command-line completion callback/registration or terminal command/parameter completion result type. Editor completion, run detectors, keyed terminals and the Artisan command workspace do not provide shell completion. This specific terminal integration remains ABI unavailable.

## Commit checks and Qodana

[CommitChecks::check](https://github.com/l0ng-ai/openidea/blob/37c2a60/sdk/rust/openidea-plugin/src/commit.rs), the `commitChecks` manifest provider and `vcs.read` capability exist. Commit checks cannot be excluded as a generic missing API. A separate undocumented Git/LLM workflow must not be invented from that availability.

The documented Qodana contract is Laravel inspections running in Qodana: [LaravelFunctionsInspection](https://www.jetbrains.com/help/inspectopedia/LaravelFunctionsInspection.html) explicitly identifies Laravel Idea's inspection and Qodana for PHP. [Qodana configuration](https://www.jetbrains.com/help/qodana/configuration-reference.html) uses IntelliJ inspection/plugin configuration. A generic Docker command, SARIF viewer or OpenIDEA check runner does not implement this contract. This Wasm plugin has no Qodana/IntelliJ-compatible inspection adapter; that is remaining product/adapter work, not an absent OpenIDEA callback and not an implemented integration.

## Application Laravel MCP

`mcpServers` inventories owned literal `Laravel\\Mcp\\Facades\\Mcp::local/web` registrations through the PHP identity resolver. Explicit connect initializes the selected application's server and lists advertised tools/resources/prompts with pagination. It does not invoke tool handlers, read resource content or retrieve prompt content. Local discovery starts the reviewed runner's `artisan mcp:start NAME`, then kills that child. Loopback HTTP discovery uses an explicitly selected origin and optional host-secret authorization header; source registration does not prove which running HTTP app owns a URL. Captures bind project, runner/Docker evidence, source registration, application PHP sources and runtime inputs. Discovery executes project bootstrap/server lifecycle only after review; inventory and cached metadata reads never execute PHP.

The authored disposable fixture installer is `plugins/laravel/tests/fixtures/prepare-application-mcp.php`. It requires a disposable `laravel-mcp-milestone6-*` application with installed `laravel/mcp`. Its tools/resources/prompts write a failure marker if handlers run. The ignored native acceptance test uses the production stdio discovery parser, not the IDE plugin's unrelated MCP server harness. Installed `laravel/mcp` v1.2.0 stdio and real loopback HTTP acceptance passed: exact tool input schema, resource URI and prompt metadata were discovered through the production parsers; the handler-execution marker stayed absent. Five source/mock/installed-package tests passed including both real transports. The HTTP fixture substitutes a curl transport for native host fetch; this does not claim desktop capability/credential approval acceptance or a live remote deployment receipt.

## Qodana adapter acceptance prerequisites

A Qodana receipt requires a Qodana-compatible IntelliJ inspection plugin/adapter artifact, an installed/pinned Qodana for PHP runtime and a PHP source fixture. The current OpenIDEA Wasm artifact is not that plugin. The adapter must register its own inspection identity (or an explicitly compatible Laravel inspection identity), accept a Qodana inspection profile, report source locations and honor suppression comments. Run an authored fixture containing an `env()` call outside a configuration file, the corresponding allowed config call and a suppressed violation. Assert the emitted SARIF rule/location/severity and suppression behavior, and prove the finding was emitted by this adapter rather than the already bundled Laravel Idea inspection. Qodana Cloud upload/account access is a separate optional receipt; running a generic scan or showing another plugin's report does not satisfy adapter acceptance. No such adapter artifact or receipt exists in this repository today.

## Current Blade and SQL source evidence

Compiled Blade footer markers resolve only owned original `.blade.php` files. Captured frames retain compiled/original hashes and a separate `exactLine` proof. Unique unchanged lines or emitted expression tokens can establish a current original source line; other generated scaffolding opens the original file with an explicit unavailable-line label. Navigation compares the captured proof again and refuses changed source/compiler files. Installed Laravel compilation/rendering tests cover inline echoes, conditionals, foreach expressions, PHP blocks, include parent/child frames, conditional includes and ambiguous duplicate expressions.

SQL sources retain schema-qualified table identities. Literal CREATE/ALTER ADD/CHANGE/MODIFY/DROP/RENAME evolution and constraints are ordered; source constraint metadata records primary/unique/foreign/check/index/default declarations, their column identities, references and partial-index status without exporting row data or CHECK/predicate expressions. Unsupported procedural/expression-based/malformed evolution produces anchored incomplete-source diagnostics instead of a silent complete catalog. Qualified tables never acquire guessed default-schema aliases. In-memory SQLite execution and static MySQL/PostgreSQL/SQL Server fixtures are separate acceptance tiers; offline fixtures do not establish live acceptance against every database server/version.
