Header variants

Original 41 px headers, 26 px icon buttons, and 360 × 191 px starting frames. Right-click a header, use Shift+F10, or open its ⋮ menu.

Right-click proposal

Window header: move, maximize, restore, or hide the pane. Resource row: open source, copy path, find usages, or refresh. The ⋮ button exposes the same actions.

These are interactive previews. Docking actions describe a proposed host command; they do not change IDE window placement.
